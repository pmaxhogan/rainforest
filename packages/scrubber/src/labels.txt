# Structural UI label strings that survive scrubbing verbatim. Parsers anchor on these.
#
# One label per line. Matching is case-insensitive with whitespace collapsed and an
# optional trailing ":" "," or ".". A label is kept when it is the whole trimmed text node,
# or when it LEADS the node (the rest is a value and is synthesized). Only labels marked
# "suffix" or "rating" may END a node instead. Inside name and address blocks only whole
# labels and labels with a kind apply, so a surname or city word that happens to be a
# label is still replaced.
#
# Optional "| kind" tells the scrubber what the value next to the label is:
#   name           a person's name -> synthetic name list
#   place          a delivery location -> fake city and reserved ZIP
#   name-or-place  either, split on " - "
#   rating         the head is a star rating -> synthetic rating in 1.0..5.0
#   asin           a 10-character ASIN or ISBN -> reserved fake ASIN
#   whole          only kept as the entire text node, never as a prefix or suffix
#   suffix         kept as the entire node or when it ENDS the node, never as a prefix
#   word           a single word kept wherever it stands as a whole word (outside address
#                  blocks); only for generic unit and frequency words
#
# Never add anything that could be personal: no names, places, product words or digits.
